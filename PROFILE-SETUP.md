# Profile setup

This repository is intended to be `haidar-farhat/haidar-farhat`.

## 1. Replace the profile repository

Create or use the public repository named exactly `haidar-farhat` under the `haidar-farhat` account. Put the contents of this package at its root.

## 2. Enable the snake workflow

Open **Actions** and allow workflows if GitHub asks. Run **Generate contribution snake** once manually. The scheduled job refreshes it daily.

After the first successful run, replace the placeholder image in `README.md` with:

```html
<div align="center">
  <img src="https://raw.githubusercontent.com/haidar-farhat/haidar-farhat/output/github-contribution-grid-snake.svg" alt="Contribution snake" width="100%" />
</div>
```

## 3. Update the real links

Replace the generic LinkedIn URL with your actual public profile. Add a portfolio URL later if you have one.

## 4. Pin the right repositories

GitHub's profile page also has a separate **Pinned** repositories area outside the README. Pin your strongest projects there; the README cannot control that area.

## 5. Optional repository metadata

Set the profile repository description to something like:

> AI Engineer building LLM systems, computer vision, automation, and full-stack products.

Use a concise social preview image for the repository if desired; the supplied `assets/hero.svg` can be exported to PNG for that purpose.
